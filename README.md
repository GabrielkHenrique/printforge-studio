# PrintForge Studio 🚀

> Parametric 3D CAD & AI Copilot for 3D Printing

PrintForge Studio is a modern, canvas-first parametric CAD application built for 3D printer owners and makers. It features an integrated Three.js viewport, tactile parametric controls, Bambu/Prusa slicer telemetry, and an autonomous AI Copilot that translates natural language requests into watertight 3D models.

## ✨ Features
- **3D Parametric Stand Generation:** Real-time geometry calculation for phones, tablets, and game controllers (PS5, Xbox, Switch).
- **AI Design Copilot:** Natural language tuning with structured Parametric Diff Receipts and printability audits.
- **Bambu-Grade Slicer Telemetry:** Live calculations for filament weight (PLA grams), material cost, and print time.
- **1-Click Binary STL Export:** Watertight meshes ready for instant slicing in Bambu Studio, OrcaSlicer, Cura, or PrusaSlicer.
- **Camera Presets & Viewport Gizmos:** Isometric, Front, Side, Top, Wireframe, and Turntable animation.

## 🛠️ Tech Stack
- Three.js (WebGL rendering, OrbitControls, STLExporter)
- Modern ES Modules
- Tailwind CSS & Custom Glassmorphic Design System
